# Cómo instalar Derivada Lab como estudiante

Tu docente debe compartirte el enlace de la aplicación ya publicada, por ejemplo en GitHub Pages. **No necesitas descargar el ZIP del proyecto ni instalar Visual Studio Code.**

## Android

1. Abre el enlace de la aplicación en **Google Chrome**.
2. Toca el menú de **tres puntos ⋮**.
3. Busca **Añadir a pantalla de inicio** o **Instalar aplicación**.
4. Confirma con **Instalar** y abre Derivada Lab desde su icono.

Si la aplicación muestra un botón directo de instalación, también puedes usarlo y seguir la confirmación del navegador.

## iPhone o iPad

1. Abre el enlace en **Safari**.
2. Toca **Compartir**.
3. Selecciona **Añadir a pantalla de inicio**. Si no aparece, revisa las acciones del menú.
4. Si aparece **Abrir como app web**, actívalo. Toca **Añadir**.

## Computadora

1. Abre el enlace en **Chrome o Edge**.
2. En Chrome, abre el menú ⋮ y busca **Instalar página como aplicación**, que puede estar dentro de **Enviar, guardar y compartir**. En Edge, busca **Aplicaciones → Instalar este sitio como aplicación**.
3. Sigue la confirmación del navegador y abre Derivada Lab desde tus aplicaciones.

## Si no aparece la opción

- Abre el enlace directamente en Chrome o Safari, fuera del navegador interno de WhatsApp o Instagram.
- Usa la dirección HTTPS publicada por tu docente. No abras los archivos del proyecto ni uses el localhost de otro equipo.
- Si ya está instalada, busca el icono en tu dispositivo.
- Las opciones cambian según el navegador y su versión. Puedes seguir usando la aplicación en el navegador si tu dispositivo no ofrece instalación.

Instalarla no crea una cuenta automáticamente. El registro y los retos con cuenta necesitan internet y que el docente haya activado Supabase. Después de una primera carga completa, el modo Invitado, las lecciones y el laboratorio gráfico pueden usarse sin conexión.
